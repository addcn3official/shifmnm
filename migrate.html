เครื่องมือย้ายข้อมูลเดิม (Google Sheet) → Firebase (Firestore)

หน้านี้ใช้ครั้งเดียวตอนย้ายระบบจาก Apps Script + Google Sheet มาเป็น Firebase — ดึงข้อมูลปัจจุบันทั้งหมดจาก Apps Script URL เดิม (ยังใช้อ่านได้ตามปกติแม้จะเลิกใช้เป็น backend หลักแล้ว) แล้วเขียนเข้า Firestore ของโปรเจกต์ ใหม่ตามค่า firebaseConfig ด้านล่าง

⚠️ ก่อนกดปุ่ม ตรวจสอบว่าใส่ค่า firebaseConfig ถูกต้องแล้ว (คัดลอกจากไฟล์ index.html ตัวเดียวกับที่ใช้จริง) และรันหน้านี้ "ครั้งเดียวเท่านั้น" — รันซ้ำจะสร้างข้อมูลซ้ำในส่วน statusLog/circuits (ส่วน records/stations จะเขียนทับด้วย id เดิมอย่างปลอดภัย ไม่ซ้ำ)
