ย้ายข้อมูลเดิม (Google Sheet) → Firebase Realtime Database

ดึงข้อมูลปัจจุบันทั้งหมดจาก Apps Script เดิม (รายการกะ, ประวัติการเปลี่ยนสถานะ, สถานี, วงจร) แล้วเขียนเข้า Realtime Database ของโปรเจกต์ shifmnm

ก่อนสลับไปใช้ index.html ตัวใหม่ กดซ้ำได้หลายรอบอย่างปลอดภัย — ข้อมูลเดิมจะถูกเขียนทับด้วย key เดิม ไม่เกิดข้อมูลซ้ำ จึงควรกดอีกรอบ "ทันทีก่อน" สลับ เพื่อเก็บรายการล่าสุดที่ทีมเพิ่งบันทึกลง Google Sheet ให้ครบ

⚠️ หลังสลับไปใช้ index.html ตัวใหม่แล้ว ห้ามกดอีก — เพราะจะเขียนทับสถานะ/รายละเอียดที่แก้ไขในระบบใหม่ ด้วยค่าเก่าจาก Google Sheet (ลบไฟล์นี้ออกจาก repo ได้เลยหลังย้ายเสร็จ)
